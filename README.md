# 回门宴电子请柬

独立的手机优先静态请柬，使用奶油白、细金线与墨绿配色。没有框架、外部字体、统计脚本或音乐依赖。

## 内容与资源

- `index.html`：封笺、三张照片叙事、回门宴信息及地图搜索入口。
- `styles.css`：响应式排版及 reduced-motion 支持。
- `script.js`：开笺滚动、快捷导航、地址复制及原幅照片查看。禁用 JavaScript 后正文和导航链接仍可使用。
- `assets/garden.jpg`、`assets/stroll.jpg`、`assets/portrait.jpg`：由获准公开的三张原照片压缩而来，不修改人物。

日期为 2027 年 1 月 2 日午宴，没有设置未经确认的入席时间。地图使用店名搜索，没有预设坐标；宾客需核对「常州奥体店」。

## 本地预览与发布

在仓库目录运行 `python -m http.server 8000`，访问 `http://localhost:8000`。也可以直接打开 `index.html`；地址复制需要安全上下文，失败时页面会提示手动复制。

GitHub Pages 从此独立仓库的 `main` 分支根目录发布。所有页面资源使用相对路径，支持仓库子路径部署。更新文件并推送到 `main` 后，GitHub Pages 自动重新部署。

请勿将此请柬的修改应用到其他网站仓库。
